# Stage 4.0H: optional supervised HyperX automatic monitoring

HyperX currently requires manual battery queries. This change adds optional 60/120/300-second monitoring (default off/120) with saved explicit preference, fresh session acknowledgement and successful no-HID helper preflight. It reuses the Stage 4.0F supervised helper and fixed one-shot native exchange, drops overlaps, waits a full interval after readiness/idle reconnect, and shares observations with manual checks. Candidates remain ownership/freshness ambiguous; headset connectivity is never inferred from receiver presence.

**Dependency / base:** targets actual `main` (`4dbf1a3` inspected). Includes unmerged Stage 4.0F `dbcbdea`, then the Stage 4.0H implementation. The public open-PR dashboard listed zero open PRs and API listing was Forbidden; there is no known Stage 4.0F PR number to link. Review the [Stage 4.0F branch](https://github.com/Jau1Agiota/G-Hub-battery-tray-icon-and-smartphone-app-/tree/feature/stage4-0f-hyperx-native-transport) and its included containment design. No other unmerged implementation is overwritten or duplicated. Squash after final owner review if desired; do not auto-merge.

Normally exited helpers with validated negative results use 2/5/15-minute backoff, suspending after failure four. Crash, invalid IPC, forced/unconfirmed exit or retained startup keep querying gated. Cancellation pauses; Resume cannot override native safety latches. Exact HID removal disables querying and marks cached data Stale; idle reconnect revalidates and waits a full interval. Active-query unplug can conservatively require diagnostics/restart. Production supports NGENUITY running or not observed; unknown inspection refuses. The standalone POC's original guards, Logitech behavior and `test.ps1` remain intact.

Validation: Release solution build passed with zero warnings/errors; **299 portable tests passed, 0 failed/skipped**, including all 265 baseline cases. **15** PowerShell runner checks passed. **11 Windows-specific tests compiled but were not run on Linux**. Debug win-x64 self-contained review package includes the isolated helper; use the static package gate. No battery request or Windows hardware/runtime test was executed in cloud.

Before approval: follow `docs/HYPERX_AUTOMATIC_MONITORING.md` for the user-owned Windows checklist: no-HID process/UI tests; default-off/restart consent; first request approximately 120 seconds after readiness; 10–15 minutes supervised NGENUITY/audio continuity and no helper accumulation; idle removal/Stale/reconnect; manual/automatic collision; Cancel and clean shutdown. Stop on disruption. Matching 56%, 54% and 52% owner observations support feasibility but do not prove unique response ownership or sustained polling reliability. A driver may delay OS exit indefinitely; uncertain cleanup remains disabled/quarantined.
