# Asset-driven 520×570 dashboard and automatic HyperX startup (120s default)

The prior dashboard used small outline device icons and content-driven height, and production HyperX scheduling still depended on a session checkbox. This change implements the owner's visual briefing **and subsequent automatic-startup addendum**, using the later explicit **120-second default** rather than its proposed 300.

The borderless 520×570 dashboard has three 488×132 cards, 180×112 product viewports, live native state, image-side cyan/steel/crimson glows, and a fixed visible footer. Owner-provided true-alpha PNGs are embedded through canonical, byte-identical copies; originals/history are retained and development references are excluded from publishing. Advanced settings now opens separately and cannot enlarge the dashboard. Dark/light/system and truthful stale/estimate semantics remain.

Before: launch → old default OFF/session UI acknowledgement → preflight → scheduling.
After: launch → versioned saved choice (new default ON/120) → exact metadata → query-free supervised preflight → full interval/backoff wait → one supervised candidate query. No settings visit or checkbox event is involved. Explicit OFF and valid 60/120/300 choices persist; legacy `Enabled:false` is conservatively preserved because intent cannot be inferred perfectly. Obsolete acknowledgement fields do not gate normal startup. Standalone POC guards remain.

A durable safety marker is written **before preflight/native submission**. Unverified cleanup, invalid IPC, crashes and uncertain exit remain latched across restart; UI toggles cannot clear them. Ordinary 2/5/15-minute backoff and fourth-failure suspension persist. Save failure refuses before operation. The fixed packet, native deadline, helper containment/cancellation, single-flight, NGENUITY rules, Logitech readers, G305 unsupported state, tray icon/tooltip and Refresh semantics remain intact.

Validation: startup regression first failed on the old bootstrap sequence; actual coordinator startup/restart tests now pass without UI. Release build PASS, zero warnings/errors; **368 portable tests passed, 0 failed/skipped**. **27 Windows-specific cases compiled, not run on Linux**. Alpha audit/black-light compositing passed for all selected images; old RGB/checkerboard versions are excluded. Debug win-x64 artifact must include the helper and pass the static package gate.
